## 发布版本的赞助开关

编辑正在发布的 `public/ai-quests/site-config.json`：

```json
{
  "showSponsor": true
}
```

- `true`：显示中文首页赞助按钮。
- `false`：隐藏赞助按钮，不加载赞助弹窗模块或二维码。
- 必须使用JSON布尔值，不要给true/false加引号。保存后刷新网页即可，不用重建、不用重启Node或Nginx。
- 本机4192与9091共用public目录，因此读取同一份配置；部署到另一台服务器后，可独立修改那台服务器的配置。
- 构建只在文件缺失时从`local-features/site-config.default.json`初始化，已存在的部署配置会保留。运行时文件是可编辑配置，不列入生成文件固定哈希。
- 配置请求不使用浏览器缓存；文件缺失、格式错误或值不是布尔true时，赞助入口保持隐藏，游戏正常加载。

验证：`npm run verify:sponsor-config`实际修改配置并测试两种服务，结束后恢复原文件；启用状态完整UI检查仍用`npm run verify:sponsor`，该检查会在隔离浏览器中固定启用，不改变你的部署设置。切换不自动推送到已打开的页面，需刷新。

## 目录与本地适配

- `public/`：本地服务唯一公开的网页与资源目录。
- `upstream-text/`：官方HTML、JS、CSS、JSON、SVG等文本原件，供对照及后续汉化；二进制原件保存在public，其原始哈希见清单。
- `reports/manifest.json`：来源URL、文件路径、字节数、原始SHA-256、内容类型及失败候选。
- `reports/local-modifications.json`：本地适配后的文本哈希及对应原件哈希。
- `reports/`：离线页面、关卡、语言、完整性、安全、依赖审计及外链归档结果。
- `scripts/`：下载、构建、服务器和验证脚本。
- `archive-config.json`：固定归档快照，重新运行下载脚本不会主动切换快照。
- `tooling/`：仅用于尝试归档外部展示视频的下载工具，不参与游戏运行。

保留官方游戏、文字及素材。CDN地址改成本地路径，移除Google Analytics/Tag Manager、Partytown、无需使用的Cookie通知及预加载提示；原件保留供对照。游戏免费使用；中文首页另有完全自愿的维护赞助入口，不影响免费使用。没有增加登录或聊天服务。服务仅允许GET/HEAD，支持媒体Range请求，提供CSP等安全响应头。
