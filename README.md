# AI Quests 简体中文版

AI Quests 是 Google Research 与斯坦福大学学习促进中心共同推出的 AI 游戏化学习体验，面向约 11–14 岁学生。本项目基于官方公开版本提供简体中文适配，适合孩子自主探索，也可用于家庭陪伴学习和课堂教学，免费使用。

## 三个探索任务

| 任务 | 学习主题 |
|---|---|
| 集市沼泽（Market Marshes） | 了解如何利用数据和 AI 预测洪水 |
| 暮色沙丘（Dusky Dunes） | 探索 AI 如何辅助眼病筛查与失明预防 |
| 极地之巅（Polar Peaks） | 体验脑科学数据标注与大脑图谱绘制 |

## 主要特色

- 简体中文界面、任务题目、对话与视频字幕。
- 五份中文教师 PDF，配套英文原版资料。
- 保留英文及其他原有语言，可在页面中切换。
- 游戏主体资源可在本地使用，进度自动保存在当前浏览器。

## 使用方式

安装 Node.js 后，双击“启动AI-Quests.cmd”，在浏览器打开[简体中文版](http://127.0.0.1:4192/ai-quests/intl/zh_cn)。结束时双击“停止AI-Quests.cmd”。

建议使用电脑浏览器，窗口至少为 1024×600。配音及图片、视频内嵌英文保留原版；学生展示页的 YouTube 视频需要联网。更换浏览器、访问地址或清除站点数据后，学习进度不会自动同步。

本项目为非官方中文适配，原素材、标识与版权归原权利方所有。了解原项目可访问 [AI Quests 官方网站](https://research.google/ai-quests/)。
