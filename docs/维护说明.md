# 构建与维护

## 目录

- public/：静态网页与资源。
- upstream-text/：官方文本原件，只读；二进制原件保存在public，原始哈希见reports/manifest.json。
- localization/zh_cn/：中文译文、界面字典及教师资料源稿。
- scripts/：构建、只读服务和验证脚本。
- reports/：生成文件清单、完整性与验证结果。
- deployment/aliyun/：云端发布与运维说明。

固定官方内容快照为20261023-141713；前端构建为73ffd59-1792762873172。原版基线标签为official-baseline-2026-11-08。

## 构建

从项目根目录运行：

```powershell
python scripts/build-local.py
```

脚本从保留的官方文本生成本地版本，再生成中文数据、界面、字幕及教师PDF。不要手工修改生成的public文件。维护生成文件和本地哈希时保留原始哈希。

教师PDF构建需要Python的reportlab、PyMuPDF及Windows微软雅黑字体；仅构建时需要，日常访问只需Node.js。迁移系统时需调整字体路径。

中文翻译参考notwin/coopa-study固定提交9ea4b867ce4857779d3cf84bfb423d12c7136049；参考文件和来源在localization/reference/coopa-study，许可见THIRD_PARTY_NOTICES.md。该仓库属于插件作者，不是Google官方仓库。

## 验证

启动本项目4192服务后执行：

```powershell
npm run verify:files
npm run verify:zh
npm run verify:locales
npm run verify:pages
```

验证使用Playwright及脚本指定的本机Chromium，迁移时检查路径。测试使用独立浏览器存档，不操作个人进度。具体覆盖范围与执行结果以reports和WORKLOG.md为准；没有逐题验证所有分支，不把首场景通过等同全关卡验收。

只读服务监听127.0.0.1:4192，允许GET/HEAD及媒体Range，保留CSP和私有目录隔离。不要修改其他项目或按端口结束其他进程。

## 版本恢复

文本使用Git，音视频、图片、字体、模型和PDF使用Git LFS。新电脑先安装Git LFS，克隆后运行git lfs pull和git lfs fsck；网页ZIP可能只有指针文件。

变更过程写WORKLOG.md，决策写DECISIONS.md，README只介绍软件。云端步骤见deployment/aliyun/README.md；本机和公网属于不同浏览器来源，进度不会自动互通。
